# Norm ledger: Finnish practice versus a model's defaults

Part of the shared content guideline (`docs/content-guideline.md`). It is the **context** every brief starts from and
the **ground** every checker tests against (operator, 2026-11-22: "this is context and grounding").

## How to read it

The shared values are the same in Finland and elsewhere: dignity, no harm, privacy, honesty, care for the student.
What differs is the **custom** that expresses them. A model trained mostly on English writes US and English customs
by default and takes them for neutral; this ledger names each default so it can be seen as a choice.

The frame is consistent with published work. On values surveys, one model's (GPT-4o's) default answers sit closest
to Finland, within a cluster of English-speaking and Protestant European countries (Tao et al. 2024, *PNAS Nexus*
3(9):pgae346), and Finland is near the US in cultural distance
(Muthukrishna et al. 2020, *Psychological Science* 31(6):678–701, Table 1: .072). These measure survey values only; they are
consistent with the difference lying in customs but do not prove it. A rough test for the level: a moral principle
would still hold without any authority requiring it, and everywhere; a custom depends on place and authority
([SEP, "The Moral/Conventional Distinction"](https://plato.stanford.edu/entries/moral-conventional/), 2022). Research
disputes whether cultures draw that line differently (the same entry: "the jury is still out"), so a level still
needs a basis. Disagreement on a value question is weighed, not settled
by one verdict, and that is not relativism ([SEP, "Value Pluralism"](https://plato.stanford.edu/entries/value-pluralism/),
rev. 2023).

Each row is **descriptive**: what Finnish practice is, with its basis. It is not a list of commands, so that a writer
can reason about cases the ledger does not cover. The **level** says what kind of norm it is and how fixed it is:

- **law** — set by a statute; fixed.
- **moral principle** — the shared value; fixed.
- **institutional rule** — set by an authority such as OPH, YTL or a professional body; fixed for that domain.
- **organisational recommendation** — advice from an expert organisation; followed unless there is a reason.
- **custom** — how things are usually done in Finland; followed, and open to the operator's judgement.
- **house style** — the sites' own choice; never taught to students as a norm.

A row is added or changed only with a basis: a source a person opened, or an operator decision. A model's opinion is
not a basis. A national-character claim ("Finns are quiet") is not a basis either: the silent-Finn image has been
called an academic myth lacking empirical evidence ([Olbertz-Siitonen & Siitonen 2015](https://journal.fi/sosiologia/article/view/124209),
*Sosiologia* 52(4)). Nor is a national score from a culture model (Hofstede, GLOBE): such scores are relative averages
and individuals differ (FAQ of The Culture Factor, formerly Hofstede Insights), and differences between groups within
a country can exceed differences between countries (Atari et al. 2023: religion SD 2.16, nation SD 0.36; Graham et
al. 2011 suggest the same for East–West differences in moral foundations). When a writer meets a norm question the ledger does not cover, they ask the operator
(guideline §5).
